# World Progression 0.34.44 hotfix

These replacement files apply to the 0.34.43 source bundle. The workshop HUD and held item are hidden during the first-person work sequence. Station work and artisan demonstrations are limited to three blocks. The complete source archive and built mod are attached to the `v0.34.44` release.

Build target: Minecraft 1.21.1, Fabric, Java 21. Multiplayer servers and clients must use the same updated mod.
