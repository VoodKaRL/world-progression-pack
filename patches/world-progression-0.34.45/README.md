# World Progression 0.34.45 hotfix

Based on the 0.34.44 workshop animation and interaction range release. Vanilla first-person hands and held items are now disabled during the workshop sequence, while the animated arms remain rendered as world geometry. The renderer state is restored after each frame.

Build target: Minecraft 1.21.1, Fabric, Java 21. Multiplayer servers and clients must use the same updated mod.
