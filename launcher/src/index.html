SOLO LA PRIMERA VEZ

Un paso antes de jugar.

Usamos Prism para conectar tu cuenta Microsoft y preparar Minecraft de forma segura. Es normal que se abra su ventana.

  1. Entra en Ajustes → Cuentas. Agrega tu cuenta Microsoft con Minecraft Java.
  2. Termina el inicio de sesión. Después, cierra Prism.
  3. Vuelve a Verdania. Verifica los archivos y pulsa Lanzar juego.

En el primer lanzamiento también puede descargar Java y Fabric.

 PRIMER LANZAMIENTO

Minecraft se está preparando.

Prism es el motor que usamos para iniciar Minecraft. La primera vez puede mostrar una ventana mientras descarga Java y Fabric.

  1. Espera a que termine la preparación. Puede tardar unos minutos.
  2. Si pide tu cuenta, inicia sesión con Microsoft.
  3. Minecraft se abrirá al terminar. Después podrás lanzar desde Verdania.
